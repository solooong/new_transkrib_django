# Транскриб — веб-интерфейс транскрибации (Django + Docker)

Лёгковесный веб-интерфейс для запуска внешнего скрипта транскрибации
(`scripts/1.py`) с авторизацией, загрузкой файлов, живыми логами,
результатами и дашбордом мониторинга системы. Работает локально в Docker.

## Быстрый старт

```bash
# 1. Положите ваш скрипт распознавания в папку scripts как 1.py
cp /путь/к/вашему/скрипту.py scripts/1.py

# 2. Соберите и запустите
docker compose up --build

# 3. Откройте http://localhost:8000
#    Вход: admin / admin (создаётся автоматически при первом старте)
```

## Что внутри

| Компонент | Назначение |
| --- | --- |
| `core/models.py` | `Task` (статус/прогресс/файлы), `TaskLog` (построчный журнал), `SystemMetric` (история метрик) |
| `core/utils.py` | Запуск `scripts/1.py` в фоновом потоке: стриминг stdout в журнал, парсинг прогресса `NN%`, коды выхода |
| `core/metrics.py` | Фоновый сборщик psutil (CPU/RAM/диск/сеть, GPU через pynvml, если установлен) каждые 2 с |
| `core/views.py` | Страницы + JSON API: `/api/metrics/`, `/api/tasks/`, `/api/task/<id>/logs/?since=<id>` |
| `static/core/js/` | Скрипты отображения: поллинг API, canvas-датчики и график нагрузки, live-таблица, стриминг лога |
| `seed_demo` | Демо-пользователь `admin/admin`, примеры задач и предзаполненная история метрик |

## Как это работает

1. На странице **«Новая задача»** загружаете аудио (mp3/wav/m4a/… до 2 ГБ).
2. Задача создаётся со статусом **«В очереди»** и запускается в фоновом потоке
   (параллельность ограничена `MAX_CONCURRENT_TASKS`).
3. Воркер вызывает `python scripts/1.py --input … --output media/results/task_<id>/`
   и построчно пишет вывод в журнал — он виден на странице задачи в реальном времени.
4. Код выхода `0` → статус **«Завершено»**, файлы из папки результатов можно скачать.
   Любой другой код → **«Ошибка»** с кнопкой **«Повторить»**.
5. Дашборд каждые 2 секунды опрашивает `/api/metrics/` и обновляет датчики,
   график нагрузки и таблицу задач без перезагрузки страницы.

## Переменные окружения

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `TRANSCRIBE_SCRIPT` | `scripts/1.py` | Путь к внешнему скрипту |
| `TRANSCRIBE_CMD` | — | Полная команда с `{input}`/`{output}`, если аргументы другие |
| `MAX_CONCURRENT_TASKS` | `1` | Одновременные задачи |
| `METRICS_INTERVAL` | `2` | Интервал сбора метрик, сек |
| `DJANGO_DEBUG` | `1` | Режим отладки |
| `DJANGO_SECRET_KEY` | dev-ключ | **Обязательно задайте в продакшене** |

## Полезное

- Логи Django: `logs/django.log` (volume, ротируются по 5 МБ).
- Админка Django: `http://localhost:8000/admin/`.
- Скрипт `1.py` проектом не модифицируется — просто заменяйте файл в `./scripts`
  и он подхватится при следующем запуске задачи (перезапуск контейнера не нужен).
- Для продакшена: `DJANGO_DEBUG=0`, свой `DJANGO_SECRET_KEY`, gunicorn вместо runserver.
