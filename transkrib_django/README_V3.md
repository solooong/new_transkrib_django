## 🎯 Новые возможности

### 1️⃣ Динамические настройки (Constance)

**Где:** Админка → Constance

**Что можно менять:**
- `MAX_CONCURRENT_TASKS` — максимальное количество одновременных задач
- `RUNNER_SECRET` — секрет защиты callback-API
- `DEFAULT_LANGUAGE` — язык транскрибации по умолчанию
- `DEFAULT_MODEL` — модель Whisper по умолчанию
- `TASK_TIMEOUT_MINUTES` — таймаут выполнения задачи
- `ENABLE_DIARIZATION` — включить диаризацию по умолчанию

**Преимущество:** Изменения применяются мгновенно без перезапуска контейнера!

### 2️⃣ Управление скриптами

**Где:** Админка → Скрипты транскрибации

**Что можно делать:**
- Загружать новые скрипты транскрибации (.py файлы)
- Указывать название, описание, модель
- Активировать/деактивировать скрипты
- Устанавливать скрипт по умолчанию

**Примеры скриптов:**
- `whisper_large.py` — высокое качество, медленно
- `whisper_medium.py` — баланс качества и скорости
- `whisper_base.py` — быстро, но менее точно
- `whisper_turbo.py` — быстро и качественно

**Безопасность:** Скрипты сохраняются только в `./scripts/`, runner проверяет путь.

### 3️⃣ Ролевая модель

**Где:** Админка → Пользователи → Группы

**Роли:**

| Роль | Задачи | Скрипты | Настройки | Пользователи |
|------|--------|---------|-----------|--------------|
| **Клиент** | Только свои | ❌ | ❌ | ❌ |
| **Оператор** | Все | ✅ | ✅ | ❌ |
| **Суперпользователь** | Все | ✅ | ✅ | ✅ |

**Как назначить:**
1. Откройте "Пользователи"
2. Выберите пользователя
3. Добавьте в группу "Клиенты" или "Операторы"
4. Сохраните

## 🎨 Примеры использования

### Пример 1: Изменение таймаута

1. Откройте админку → Constance
2. Измените `TASK_TIMEOUT_MINUTES` с 60 на 120
3. Сохраните
4. ✅ Новые задачи будут использовать таймаут 120 минут

### Пример 2: Добавление нового скрипта

1. Создайте файл `whisper_turbo.py` в `./scripts/`
2. Откройте админку → Скрипты транскрибации
3. Загрузите файл, укажите название "Whisper Turbo"
4. Установите "Скрипт по умолчанию"
5. ✅ Теперь все новые задачи будут использовать этот скрипт

### Пример 3: Назначение роли

1. Создайте нового пользователя в админке
2. Добавьте его в группу "Клиенты"
3. ✅ Пользователь теперь видит только свои задачи
