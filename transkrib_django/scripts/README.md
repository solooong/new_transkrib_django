# scripts/ — папка внешнего скрипта транскрибации

Сюда кладётся ваш файл **`1.py`**. Проект его **не изменяет** — он подключается
в контейнер volume-ом `./scripts:/app/scripts` и вызывается **Flask-runner'ом**
как внешний процесс.

## Контракт вызова (версия 2)

Runner запускает:

```
python scripts/1.py --input <путь к загруженному файлу> --output <папка результатов>
```

- `--input` — файл из `media/uploads/…`
- `--output` — папка `media/results/task_<id>/` (создаётся заранее)

### Что runner делает с выводом скрипта

1. **Журнал.** Всё, что скрипт пишет в stdout/stderr, построчно отправляется в
   Django (уровни info/ok/warn/err — по ключевым словам error/warn/done).
2. **Прогресс.** Строки вида `… 47% …` автоматически обновляют прогресс-бар.
3. **Результат.** После успешного завершения (код 0) runner ищет в папке
   `--output` файл транскрипта — приоритетно `transcript.txt` или `транскрипт.txt`,
   иначе первый попавшийся `.txt` — читает его и передаёт в Django. Текст
   сохраняется в базе, отображается на странице задачи и скачивается как `.txt`.
4. **Код выхода.** `0` → «Завершено», любой другой → «Ошибка» (текст — в карточке).

## Настройки (в `.env`)

| Переменная | По умолчанию | Описание |
| --- | --- | --- |
| `TRANSCRIBE_SCRIPT_DIR` | `scripts` | Каталог, куда кладётся файл скрипта |
| `TRANSCRIBE_SCRIPT_NAME` | `1.py` | Имя файла скрипта внутри каталога |
| `MAX_CONCURRENT_TASKS` | `1` | Сколько скриптов runner запускает одновременно |

Менять файл `1.py` на хосте можно без пересборки образа — он подхватится при
следующем запуске задачи.
